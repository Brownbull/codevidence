## Codebase Patterns

- **Dual runtime context**: `src/app/` = browser/React (DOM types), `src/pipeline/` = Node.js (no DOM). Enforce with separate tsconfigs (done in US-002).
- **Firestore wrapper**: ALL Firestore access via `src/core/db/firestore.ts`. Never import Firebase SDK directly in business logic.
- **aiMaturityScore invariant**: `null` = not scored, `0` = scored Level 0. Pipeline scoring output type MUST TypeScript-exclude aiMaturity fields.
- **Build check**: `pnpm build` runs `tsc --noEmit && vite build && classpresso optimize` — all three must pass.
- **classpresso**: Works with empty dist (0 patterns is fine exit 0). No special config needed.
- **JSX in tsconfig**: Base `tsconfig.json` needs `"jsx": "react-jsx"` and `"lib": ["ES2022", "DOM", "DOM.Iterable"]` for typecheck (`tsc --noEmit`) to work across app + pipeline together.
- **tsconfig.pipeline.json**: Has `"lib": ["ES2022"]` + `"types": ["node"]` — NO DOM lib. Child configs override lib from base.
- **Firebase emulators**: `firebase.json` configures Firestore port 8080, Auth port 9099. `.env.local` (gitignored) sets `VITE_USE_EMULATOR=true`, `FIRESTORE_EMULATOR_HOST`, `FIREBASE_AUTH_EMULATOR_HOST`.
- **CI gate**: `.github/workflows/ci.yml` — `ci` job runs on all branches; `deploy` job gates on `refs/heads/main` only.
