## Codebase Patterns

- **Dual runtime context**: `src/app/` = browser/React (DOM types), `src/pipeline/` = Node.js (no DOM). Enforce with separate tsconfigs (US-002).
- **Firestore wrapper**: ALL Firestore access via `src/core/db/firestore.ts`. Never import Firebase SDK directly in business logic.
- **aiMaturityScore invariant**: `null` = not scored, `0` = scored Level 0. Pipeline scoring output type MUST TypeScript-exclude aiMaturity fields.
- **Build check**: Use `pnpm vite build` (not `pnpm build`) to skip the `postbuild` classpresso step during scaffold verification.
- **JSX in tsconfig**: Base `tsconfig.json` needs `"jsx": "react-jsx"` and `"lib": ["ES2022", "DOM", "DOM.Iterable"]` for typecheck to work across app + pipeline together.
